# OCR Review Procedure

## 1. Prepare
Confirm the source file is readable and that you are permitted to process and publish a demonstration copy. Retain an untouched source privately where required by the project rules.

## 2. Compare
Review the extracted text line by line or field by field against the source. Pay special attention to:
- Similar-looking characters such as `O` and `0`, `I` and `1`, or `S` and `5`.
- Decimal points, commas, currency symbols, fractions, and percentages.
- Dates, names, addresses, IDs, and reference numbers.
- Table rows, columns, headings, and reading order.

## 3. Correct
Make only corrections supported by the source. Preserve the source's intended structure. If the source itself is unclear, mark the item uncertain rather than inventing a value.

## 4. Record
Use the review log to capture the document ID, page, field, raw OCR text, corrected text, issue category, reviewer note, and QA status. Do not expose confidential source files or personal data in a public repository.

## 5. Final QA
Recheck all corrected values against the source and verify that no text has shifted into the wrong field or column.
